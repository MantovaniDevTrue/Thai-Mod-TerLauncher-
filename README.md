# Terraria ภาษาไทย — TLPro

Thai localization for **Terraria Mobile** running through **TLPro / TerLauncher**.

This project adds Thai text and Thai font support across menus, UI, items, tooltips, buffs, NPCs, projectiles, and other supported game content while keeping the mobile layout readable.

## Download

The ready-to-use mod is in [`Release/Terraria_Thai_TLPro_v1.0.tl`](Release/Terraria_Thai_TLPro_v1.0.tl).

## Installation

1. Download the `.tl` file from the `Release` folder.
2. Import it into TLPro / TerLauncher.
3. Enable the mod and launch Terraria.

## Repository layout

- `Release/` — ready-to-use `.tl` release.
- `Source/` — clean source archive with the complete TLPro package structure, human-readable Thai localization catalog, runtime catalog, font metadata and assets.
- `Licenses/` — font license notice.
- `CHANGELOG.md` — release history.
- `CONTRIBUTING.md` — bug-report information.
